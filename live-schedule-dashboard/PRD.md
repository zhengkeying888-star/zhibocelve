# 直播排期策略看板 — 产品需求文档 (PRD)

## 1. 背景与目标

### 1.1 背景
私域直播运营团队每周需要完成大量直播排期工作。排期涉及：
- 确定一周内每天各时段的直播场次
- 为每一场直播分配对应的 audience 人群（存量用户）
- 根据历史跨科数据预估转化和 GMV
- 避免同一用户在短时间内被重复触达（频控）

目前排期主要依赖运营人工在 Excel 中完成，效率低、容易出错、难以做数据归因。

### 1.2 目标
构建一个**直播排期策略看板**，让运营能够：
1. 上传现有排期 Excel，系统自动解析直播场次
2. 上传 audience 量级表，系统获得可分配的存量用户池
3. 上传跨科偏好数据，系统基于历史跨科率 + LTV 做智能分配
4. 在看板上直观查看、编辑、校准排期结果
5. 一键导出排期结果回 Excel

## 2. 用户画像

- **主要用户**：私域直播运营团队（排期负责人）
- **使用频率**：每周 1-2 次（周度排期）
- **技术背景**：熟练使用 Excel，不需要编程能力
- **核心痛点**：
  - Excel 排期效率低，跨表数据难以联动
  - 不知道每个直播该分配哪个 audience 人群
  - 无法直观看到预计转化和 GMV
  - 容易违反频控规则（3天/30天/当日去重）

## 3. 核心功能

### 3.1 数据上传与解析

支持上传三个文件：

| 文件 | 必填 | 说明 |
|---|---|---|
| 直播排期表 | 是 | 运营提供的周度排期 Excel，包含直播名、时间、时段、负责人等信息 |
| 用户量级表 | 否 | 各品类各时间段的存量用户数（若排期文件中已包含可跳过） |
| 跨科偏好数据 | 否 | `公海品类-跨科品类-day60跨科率-day60LTV`，用于归因和智能排序 |

系统自动识别文件类型并解析。排期表支持多 sheet（当前 sheet + 历史 sheet 自动追溯）。

### 3.2 自动排期

上传数据后，系统自动执行 audience 分配：

**分配规则**：
- health 品 audience → health 直播
- beauty 品 audience → beauty 直播
- interest 品 audience → interest 直播
- **严禁跨线分配**
- 同品类族优先（垂类宣发）
- 同品类族内按 LTV 从高到低排序
- 每场直播有曝光目标（S:45w, A:30w, B:20w, C:15w）

**频控规则**：
- 3天频控：同一 audience 段 3 天内不能被重复触达
- 30天伪直播复用：伪直播复用的 audience 30 天内不能再复用
- 当日去重：同一天同一 audience 段只能分配给一场直播
- 跨科直播不能宣发同品类族 audience

### 3.3 手动校准

运营可以在看板上做以下调整：

- **编辑直播品类/线级**：点击直播卡片或详情面板，可修改品类、线级、是否跨科
- **品类评级管理**：为每个品类设置 S/A/B/C 评级，系统自动应用到所有对应直播
- **手动分配/移除 audience**：在详情面板右侧的人群库存中点击分配，或点击已分配人群的 × 移除
- **历史记忆**：修改后可选择"保存并记住（按直播名）"，下次上传同名直播自动应用

### 3.4 排期归因看板

全局归因弹窗，展示所有直播的数据归因：

| 字段 | 说明 |
|---|---|
| 触达人数 | 该直播分配的所有 audience count 之和 |
| 预计转化 | Σ(count × crossRate) |
| 预计 GMV | Σ(count × crossRate × ltv) |

支持按线级筛选（健康/变美/兴趣），支持点击直播名跳转到详情面板。

单直播详情面板也展示每条 audience 的 crossRate、LTV、预计转化、预计 GMV。

### 3.5 导出 Excel

一键导出排期结果到 Excel，格式与运营现有模板兼容：
- 保留原有排期结构
- 已分配 audience 以注释形式写入对应单元格
- 朋友圈资源位直播只导出资源标注行和负责人行

## 4. 数据格式规范

### 4.1 排期表结构（矩阵式）

```
| 星期 |      | 周一 | 周二 | ... |
| 日期 |      | 4/27 | 4/28 | ... |
| 早间 |
|      | 健康线 | 直播信息 | ... |
|      | 变美线 | 直播信息 | ... |
|      | 兴趣线 | 直播信息 | ... |
|      | 文案负责人 | 负责人名 | ... |
|      | 定时负责人 | 负责人名 | ... |
|      | 曝光量级 | 数字 | ... |
| 晚间 |
| ...（同上） |
```

直播信息单元格格式（多行文本）：
```
直播名称
开播时间：07:30-09:00
预约链接：xxx
```

### 4.2 Audience 量级表结构

```
| 线 | 品类 | 时间 | 用户数 | 时间 | 用户数 | ... |
| 健康线 | 睡眠调理 | 2025.1-2026.4 | 120000 | 2024.7-2024.12 | 80000 | ... |
```

### 4.3 跨科偏好表结构

```
| 公海品类 | 跨科品类 | 跨科率 | day60LTV |
| 睡眠调理 | 中医变美 | 0.15 | 200 |
| ... |
```

## 5. 用户流程

```
1. 打开看板 → 点击「上传本周数据」
2. 上传排期表（必填）
3. 上传 audience 量级表（可选）
4. 上传跨科偏好数据（可选）
5. 点击「上传并生成排期」
6. 系统自动解析 + 自动排期
7. 在看板上查看排期矩阵
8. 点击场次查看详情，手动校准品类/线级/评级/audience 分配
9. 点击「排期归因」查看全局归因数据
10. 确认无误后点击「导出 Excel」
```

## 7. 非功能需求

- **性能**：上传并解析 100 行以内的 Excel 应在 3 秒内完成
- **兼容性**：支持 Chrome、Safari、Edge 最新两个主版本
- **数据安全**：纯前端处理，不上传文件到服务器，敏感数据不出本机
- **持久化**：品类评级、线级覆盖、直播名记忆存储在 localStorage
