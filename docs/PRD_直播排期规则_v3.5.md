## 1. 概述

本规则定义从 Excel 排期表、audience 量级表、跨科偏好表、**4月直播明细表**到最终 audience 分配与 GMV 归因的全流程逻辑。

**核心变更（v3.5-redline）**：
- **规则审计面板（RuleAuditPanel）**：前端实时规则引擎，10+ 项自动检查，实时反馈排期健康度与修复建议。
- **规则库（RuleLibrary）**：14 条生效规则看板，支持分类筛选与搜索。
- **跨线合规红线**：`tryAssign` 增加底层硬性 line 校验，`seg.line` 必须在直播允许线内，任何入口（autoSchedule / 手动调整 / 审计修复）都无法突破。
- **删除 Round 5 跨线兜底**：伪直播补充轮严禁拿其他线剩余段，宁可不排也不能跨线。
- **Round 5 改为本线可复用段优先**：先找同线 unused，再找同线已用但间隔≥3天且周内未超2次的复用段。
- **所有 fake live 统一上限**：`type === 'fake'` 统一限制为最多 2 段、30w 封顶（不再只限制数字人/录播）。
- **fake live 不排除同品类**：作为后置承接资源位，真直播排完后允许吃同品类剩余库存。
- **真直播/伪直播审计分层**：真直播 <15w 标 ❌ 失败；数字人/伪直播 <15w 标 ⚠️ 警告（"后置承接不足"）；15-20w 标轻提醒（"可优化"）。
- **数字人时间固定 vs 普通伪直播可调**：数字人是固定事件，日期不可调整，只能在当前日期补同线库存；普通伪直播时间可调整以满足复用频控。
- **一键红线修复**：跨线违规时提供"移除违规人群并重排"按钮；0 曝光直播提供 blocker 原因分析。
- **库存利用率深入诊断**：分析剩余段不可用的原因（段数上限、品类族上限、小段碎片、按线分布）。

**核心变更（v3.4-merge-candidate）**：见 v3.4 PRD，此处省略。

#### Round 5：伪直播补充承接（v3.5 重大变更）

**目标**：在真直播主分配、零曝光兜底、20w 底线补齐全部完成后，为伪直播/数字人补充剩余 audience。

**严禁跨线**：只能在 `getAllowedLines(live)` 返回的允许线内取段。

**步骤**：
1. **本线 unused 段**：在允许线内找 `status === 'available' && assignedDates.length === 0` 的段。
2. **本线可复用段**：若 unused 没有，在允许线内找 `status === 'used' && assignedDates.length === 1 && daysBetween >= 3` 的复用段。
3. 若两步均无可用段，**停止分配**，不尝试其他线。

**上限约束**：
- 所有 `type === 'fake'` 统一限制：最多 2 段、30w 封顶。
- 数字人/录播仍保持低权重排序（-120 降权）。

### 10.8 段数上限与低权重直播硬性上限（v3.5 更新）

#### 低权重直播硬性上限

**定义**：直播名包含 `数字人`、`录播`、`开心太极` 的直播被视为低权重直播。

**上限规则（v3.5 更新）**：
- **所有 `type === 'fake'` 统一限制**：最多 **2 段**、累计曝光最多 **300,000**。
- 排序得分 **-120** 大幅降权。
- 数字人/录播作为后置承接资源位，允许使用同品类剩余库存（`getExcludedCats` 对 fake live 返回空 Set）。

> v3.5 变更原因：v3.4 只限制数字人/录播为 1 段，但普通伪直播复用场无上限，导致部分伪直播复用场曝光过高。统一限制为 2 段/30w 更合理。

## 14. 协作方式流程（人机对齐工作流）

同 v3.4，新增 **规则审计** 环节：

#### 阶段 3.5：规则审计（v3.5 新增）

系统排期后，运营可通过「🔍 规则审计」面板实时查看排期健康度：

| 检查项 | 说明 |
|---|---|
| 真直播 15w 不可接受底线 | 真直播 exposure < 15w 标 ❌ 失败 |
| 真直播 20w 优先底线 | 真直播 15-20w 标 ⚠️ 轻提醒（可优化） |
| 伪直播/数字人后置承接量 | 数字人/伪直播 <15w 标 ⚠️ 警告；15-20w 标轻提醒 |
| Audience 复用频控 | 3天/周2次/当日去重检查 |
| 伪直播/数字人后置承接优先级 | 检查是否挤压真直播主资源 |
| 联合直播跨线资源分配 | 检查涉及线级是否都有分配 |
| 品类映射完整性 | 检查未映射品类 |
| 跨线分配合规性 | 检查跨线违规（底层红线） |
| 同品类族排除 | 检查同品类族违规分配 |
| Segment 状态一致性 | 检查 used/available 状态 |
| Exposure 归因一致性 | 检查 exposure 与明细之和 |
| Audience 库存利用率 | 总库存、利用率、剩余段原因分析 |
| 0 曝光直播 blocker 分析 | 分析为什么 exposure=0 |

**一键修复**：
- 跨线违规 → **移除违规人群并重排**
- 真直播低量 → **为真直播补齐并重排**
- 伪直播低量 → **为伪直播补充段并重排**
- 库存利用率低 → **为伪直播预留并重排**

## 17. 待决策/待优化项

1. **历史数据趋势分析**：当前仅使用单月销量均值，未来可扩展为多月销量趋势。
2. **规则学习效果评估**：当前规则仅影响排序优先级，尚未量化规则对 GMV 的实际提升效果。
3. **多周排期批量管理**：当前为单周排期，未来可支持多周批量上传与对比。
4. **完成版排期直接回写**：当前完成版排期可正确解析并显示，但尚未支持将手动调整后的结果导出为新的"正确版排期"格式。
5. **飞书多维表格集成**：计划支持从飞书 Bitable 直接读取排期数据。
6. **伪直播自动调期（不含数字人）**：普通伪直播时间可调整以满足复用频控，需实现自动推荐最优日期。
