# 直播排期策略表 — 标准模板规范 v1.0

> 目标：让系统能**零误差解析**排期表，避免每期排期都要人工校对品类映射和规则冲突。

---

## 一、标准表头结构（不可改动）

| | A | B | C | D | E | F | G | H |
|---|---|---|---|---|---|---|---|---|
| **1** | 星期 | 直播资源位分布 | 周一 | 周二 | 周三 | 周四 | 周五 | 周六 | 周日 |
| **2** | 日期 | **【晨练】** | 18 | 19 | 20 | 21 | 22 | 23 | 24 |

**要求**：
- 第1行固定为星期行，第2行固定为日期行
- 第2行 B 列必须标注资源位类型：`【晨练】`、`【晚间】`、`【伪直播】` 三选一
- 日期只写数字（如 `18`），不写 `5/18`

---

## 二、直播名单元格格式（核心）

### 2.1 标准格式

```
品类-直播名[|时间][|标记1][|标记2]
```

**示例**：
- `国际声乐-唱歌李燃|19:00|数字人|不回捞`
- `太极-君合太极晨练|7:00-9:00`
- `瑜伽-一杰瑜伽晨练+五禽戏晨练|8:30-10:00`

### 2.2 字段说明

| 字段 | 必填 | 说明 |
|---|---|---|
| `品类` | 是 | 必须是系统标准品类名（见文末附录） |
| `直播名` | 是 | 运营侧自定义名称 |
| `时间` | 建议填 | `7:00-9:00` 或 `19:00`。不填时系统从资源位推断 |
| `标记` | 可选 | 多个标记用 `|` 分隔，支持：`数字人`、`录播`、`不回捞`、`需剪辑` |

### 2.3 联合直播格式

两个品类用 `+` 连接：

```
品类A+品类B-直播名|时间
```

**示例**：
- `瑜伽+五禽戏-晨练|8:30-10:00`

系统会解析为联合直播，涉及多线时自动允许跨线分配。

### 2.4 常见错误（不要这样写）

| 错误写法 | 问题 | 正确写法 |
|---|---|---|
| `唱歌李燃` | 系统不知道品类是"唱歌"还是"国际声乐" | `国际声乐-唱歌李燃` |
| `摄影美学-段晓晖单人` | 虽然能推断品类，但不统一 | `摄影美学-段晓晖单人` ✓（品类明确） |
| `一杰瑜伽晨练` + `五禽戏晨练`（分两个单元格） | 系统解析为两个独立直播 | `瑜伽+五禽戏-晨练`（一个单元格） |
| `数字人直播-开心太极` | "数字人直播"不是品类 | `太极-开心太极|19:00|数字人` |
| `相机摄影-助教罐头（录播）` | 括号导致解析异常 | `相机摄影-助教罐头|录播` |
| `2025.5.16健康营养` | 日期前缀不是品类 | `健康营养-伪直播复用|需剪辑` |

## 三、Audience 分配行规范

### 3.1 结构顺序（每个直播块内必须按此顺序）

```
第1行：文案负责人
第2行：曝光量级
第3行起：audience 分配（每行一个段）
```

### 3.2 Audience 行格式

**标准格式（推荐）**：
```
timeRange|品类（人数）
```

**示例**：
```
2023年1月—2026年5月10日|五禽戏（127104）
2025年10月27日—2026年5月10日|太极BCD(279756)
```

**旧格式（仍兼容，但不推荐）**：
```
【存量】
2023年1月—2026年5月10日
五禽戏（127104）
```

### 3.3 线级标签问题

**旧模板问题**：排期表里写了"健康线"、"变美线"、"兴趣线"标签，但实际品类和标签经常不匹配（如"健康线"标签下写"瑜伽BCD"）。

**新规范**：
- **不再写线级标签**。系统直接从品类名推断线级。
- 如果一定要写标签，仅作人工阅读参考，系统解析时会忽略。

### 3.4 存量标记

存量人群统一格式：
```
【存量】timeRange|品类（人数）
```

**示例**：
```
【存量】2023年1月—2026年5月10日|五禽戏（127104）
```

### 3.5 联合品类名

如果 audience 表里出现 `唱歌、短视频` 这种联合品类，系统会按顿号拆分，取**最长匹配的子品类**作为该段的品类。

**建议**：尽量避免联合品类名。如果确实是一个混合人群段，建议拆成两行：
```
2025年10月27日—2026年5月10日|唱歌（169293）
2025年10月27日—2026年5月10日|短视频（169293）
```

## 四、特殊标记规范

| 标记 | 含义 | 系统行为 |
|---|---|---|
| `数字人` | 数字人/录播直播 | `type: 'real'`，但优先级 score -20 |
| `录播` | 录播内容 | `type: 'real'`，优先级 score -20 |
| `不回捞` | 不二次营销该批用户 | 该直播的 audience **不计入 historyRecords**，不参与 3天/30天频控 |
| `需剪辑` | 素材待剪辑 | 纯运营备注，系统忽略 |
| `不回捞+数字人` | 数字人且不回捞 | 优先级降低 + 不计入频控 |

## 七、协作检查清单（每期排期后自查）

- [ ] 直播名单元格都按 `品类-直播名` 格式填写
- [ ] 联合直播用 `+` 连接（如 `瑜伽+五禽戏-晨练`）
- [ ] 数字人/录播/不回捞标记用 `|` 分隔
- [ ] audience 行不写线级标签（健康线/变美线/兴趣线）
- [ ] 存量人群标记为 `【存量】`
- [ ] 伪直播复用品类明确（不写 `2025.5.16健康营养`，写 `健康营养-伪直播复用`）
- [ ] 没有 `(` `)` 等特殊符号混杂在直播名中（用 `|` 代替）
