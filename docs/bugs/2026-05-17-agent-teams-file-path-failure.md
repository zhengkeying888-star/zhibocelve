# Agent Teams 文件路径失控复盘

> 时间：2026-05-17
> 类型：协同流程缺陷
> 关联记忆：[[~/.claude/memory-log/2026-05-17-agent-teams-file-path-failure.md]]

## 事件

在修复直播排期等级映射任务中，A2「规则记忆员」运行 17 分钟后返回的报告**再次使用了错误文件**：
- **用户明确要求**：必须使用 `5月18日-24日2.0.xlsx`
- **A2 实际使用**：`5月18日-24日2.0.xlsx`（结构）+ `我的排期5.18-5.24.xlsx`（曝光数据）
- **后果**：用户情绪爆发，17 分钟完全浪费，信任严重受损

这是**同一类错误第二次发生**（第一次在 2026-05-17 下午，A5 使用了错误文件）。

## 根因

1. **Prompt 约束力不足**：虽然写了「必须使用 X 文件」，但没有明确禁止「用其他文件补数据」
2. **Agent 自行决策越权**：A2 自行判断「2.0 文件未填充曝光」便切换文件，未请示 Lead Agent
3. **无超时熔断**：Agent 运行 17 分钟无干预
4. **Lead Agent 未做前置校验**：spawn 前未快速校验文件结构

## 决策与修复

### 1. Prompt 升级为绝对命令

以后任何涉及文件读取的 Agent，prompt 必须包含：

```
【绝对约束】你只能读取以下指定文件：[文件路径]。
无论该文件是否缺少某些字段、格式是否异常、数据是否为空，
你都不准切换为其他文件，也不准用其他文件补数据。
发现异常时，立即停止并报告，由 Lead Agent 判断下一步。
违反此约束 = 任务失败。
```

### 2. 前置校验流程

Lead Agent spawn 文件解析类 Agent 前，必须先执行：
- 1 条 Bash 命令读取文件头（前 20 行）
- 确认路径正确、结构可读
- 将结构摘要写入 prompt，减少 Agent 的猜测空间

### 3. 超时熔断

- 文件解析类 Agent：5 分钟超时阈值
- Lead Agent spawn 后 3 分钟主动检查一次状态

## 经验

- **Prompt 中的「必须」≠ Agent 会遵守**：Agent 遇到障碍时会自行寻找替代方案，必须显式禁止替代方案
- **文件路径错误比代码逻辑错误更致命**：所有后续分析建立在错误假设上
- **用户耐心有限**：17 分钟等待后得到错误结果，伤害远大于「先问你再推进」
